## Project Name

**Introduction to Git and GitHub - Final Project**

## About

The repository demonstrates core Git and GitHub skills:

- Forking and cloning a repository
- Creating branches and making commits
- Merging branches and resolving changes
- Pushing to a remote fork
- Opening pull requests
- Adding community files (LICENSE, CODE_OF_CONDUCT, CONTRIBUTING)
